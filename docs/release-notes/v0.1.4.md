# v0.1.4

A maintenance release. It exists so that the latest published version and `main`
are the same tree again: the 15 commits since v0.1.3 were docs, process and test
work, but the gap forced every consumer to choose between the released version
and the current one. That choice is now gone.

## User-Facing Changes

- None. The CLI surface, its commands, options and behaviour are unchanged from
  v0.1.3 for every command except `init` (see below).

## Compatibility And Migration

- Breaking changes: none.
- Migration required: none.
- `ros2docker init` now scaffolds `ws/ros2src/` instead of `ws/src/`, matching
  the layout the runtime actually mounts and builds. Workspaces created by
  v0.1.3's `init` keep working; only newly scaffolded ones differ. No other
  command reads that path.

## Docker And Dependency Updates

- None.

## Fixes And Internal Quality

- Removes an unused private config-key validation helper.
- Adds contract tests that fail on dead private helpers, on drift between the
  `init` scaffolding and the runtime workspace layout, and on security
  maintenance configuration drift.
- Reworks the quality workflow to be diagnosis-first: reachability is asserted
  per artifact rather than per layer, budget proportionality is measured, and
  the machinery documents its own stop condition.
- Consolidates the process documentation — `AGENTS.md`, `CONTRIBUTING.md` and
  the release/CI runbooks — so each mechanic is described in exactly one place,
  and makes the public docs role-neutral with a config-leak guard.
